Quadro de acessos

Cada linha é uma pessoa, cada coluna é um portão. O que se vê aqui é o acesso efetivo pelo SHAAR: o papel que a base de cada aplicação concede, cruzado com o que o hub tem liberado. Portão aceso, entra. Portão apagado com o papel riscado, a autorização existe na aplicação mas o hub não abre.
portão aberto — entra pelo SHAAR portão fechado — sem autorização na aplicação papel riscado — autorizado na aplicação, mas o portão está desabilitado no hub Cada aplicação decide o papel de cada pessoa; o hub decide se o portão abre.
